# سجل الاستقرار والتحقق — Flotex EGP

## التغييرات المحدودة

| المشكلة | التعديل | التحقق |
|---|---|---|
| اختبار CORS كشف أن طلبًا من أصل `localhost` غير مضبوط يمكن قبوله لمجرد أن API محلي. | قُصر السماح المحلي على أصل Expo المحلي المطابق تمامًا لـ`EXPO_PACKAGER_PROXY_URL` أو `EXPO_WEB_PREVIEW_URL`؛ بقيت الأصول العامة مقيدة بعناوين المعاينة المقترنة. لم يتغير تدفق التطبيق أو تصميمه. | نجحت اختبارات CORS الـ25 ضمن مجموعة الاختبارات النهائية. |

لم تُجرَ تغييرات أخرى على السلوك أو الشاشات عدا تهيئة إعدادات Expo اللازمة لنسخة مستقلة: احتُفظ باسم Flotex EGP وأصول المصدر وهوية الحزمة التي أنشأها مشروع Manus، وأضيف إعداد الصورة المستخدم أصلًا في مسار توثيق الهوية.

## التحقق المنفذ

- ثُبّتت الاعتماديات باستخدام `pnpm install --frozen-lockfile` من ملف القفل المرفق.
- نجح `pnpm check` بعد الدمج وبعد إصلاح CORS.
- نجح `pnpm lint`؛ ظهر تحذير Node غير مانع عن صيغة ESM لملف إعداد ESLint.
- نجحت 145/145 من الاختبارات في 26 ملفًا لا تكتب إلى قاعدة البيانات. استُبعدت مجموعات اختبارات التكامل التي قد تكتب إلى قاعدة التطوير المشتركة.
- فُحصت قاعدة البيانات الجديدة قبل التهيئة وكانت بلا جداول. طُبقت ترحيلات مصدر التطبيق عليها، وأصبح بها 32 جدول تطبيق وجدول ترحيلات Drizzle. أحد ترحيلات المصدر يصفر أرصدة محافظ قديمة؛ نُفّذ فقط في قاعدة النسخة الجديدة الفارغة، ولم تُنقل بيانات عملاء أو أرصدة من ملف ZIP.
- استجابت نقاط `/api/health` و`/api/ready` بنجاح، وأثبتت الثانية اتصال قاعدة البيانات. أعادت المعاينة العامة HTML برمز HTTP 200، وأظهر المتصفح شاشة الدخول بعد اكتمال فحص الاتصال. سمح API بأصل المعاينة العام المطابق.
- بدأت خدمتا Metro وAPI على المنفذين 8081 و3000؛ المشروع محفوظ في مساحة Manus نفسها.
- أُدخلت إعدادات Gmail OTP وHMAC التحقق بالبريد وتشفير مستندات الهوية عبر Secrets المحمية. لم تُحفظ أي قيمة سرية في الملفات أو Git أو السجل.

## حدود التحقق والتوزيع

أُجري الاختبار الكامل مرة قبل تطبيق مخطط قاعدة البيانات؛ فشلت حينها 13 حالة تتطلب جدول `users` غير الموجود في قاعدة المشروع الجديدة، بينما نجحت 166 حالة وتخطت 35. بعد تهيئة المخطط، لم تُعَد مجموعات التكامل التي يمكن أن تُنشئ مستخدمين أو سجلات مالية داخل قاعدة التطوير المشتركة. لم تُرسل رسائل OTP فعلية ولم تُنشأ معاملات مالية.

نجاح معاينة الويب لا يثبت تشغيل وظائف الكاميرا أو الإشعارات أو الاهتزاز أو الروابط العميقة على جهاز فعلي. لم يُجر اتصال Expo Go بحساب المستخدم ولم يُنشأ APK/AAB فعلي في هذه المهمة؛ إنشاء APK قابل للتنزيل يتم من لوحة المشروع بعد Connect Expo/تسجيل الاعتماد المطلوب ثم Build Android → APK. انظر `docs/android-build.md`.
