# إشعارات Push — نسخة FLOTEX EGP المستقلة

إشعارات Push على Android تتطلب ربطًا مستقلًا بين معرف الحزمة الجديد، Firebase/FCM، ومشروع Expo/EAS خاص بهذه النسخة. معرف Android الحالي `space.manus.flotexegp.t20261112164016`. لا تُستخدم أي معرفات Firebase/EAS أو مفاتيح أو رموز أجهزة من مشروع المصدر.

لا يحتوي هذا المشروع حتى الآن على إعداد Firebase/FCM أو معرف EAS مستقل أو ملف تثبيت Android. لا تحفظ مفاتيح حساب الخدمة أو `google-services.json` في Git أو Expo bundle. استخدم لوحة Manus وبيانات اعتماد Expo/EAS الآمنة، ثم ابنِ Development Build/ APK بعد تجهيز API مستقل.

المعاينة على الويب لا تختبر Push. بعد موافقة المالك وإعداد Firebase وExpo، اختبر على جهاز Android فعلي بحساب وبيانات اصطناعية فقط. لا تنشئ إيداعًا أو سحبًا أو دفعة عائد حقيقية لاختبار الإشعار. لا تعتبر وجود مسارات server أو سجل تسليم دليلًا على وصول إشعار إلى جهاز.

راجع [دليل إعداد Android](../PUSH_NOTIFICATIONS_SETUP.md) لتفاصيل خطوات المالك.
